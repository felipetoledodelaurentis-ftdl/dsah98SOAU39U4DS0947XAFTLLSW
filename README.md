# 🚀 Astronauta Murilo — Retorno à Terra

Jogo em HTML feito de presente para o **Dia das Crianças**: uma mistura de *Lunar Lander* com aventura espacial. Pilote a nave por nove planetas, resgate a família e os amigos, entre nas cavernas-labirinto cheias de guardas e aperte o botão de autodestruição para liberar cada peça da Taça do Palmeiras — e fuja antes de o planeta explodir!

## ▶ Como jogar

Abra o site publicado pelo GitHub Pages (veja abaixo) ou dê dois cliques no arquivo `index.html`.

| Ação | Teclado | Controle PS5 / Xbox | Toque |
|---|---|---|---|
| Girar / andar | ← → | analógico ou direcional | ◀ ▶ |
| Propulsão | ↑ ou espaço | R2 / RT | PROPULSÃO |
| Pular / laser | J / F | ✕ / A · □ / X | PULAR / LASER |
| Sair / entrar na nave | E | △ / Y | SAIR / ENTRAR |
| Pausa e opções | Esc ou P | START / Options | II |

**Recursos:** 10 planetas · 4 dificuldades (Fácil, Normal, Difícil e Insano) · salvar e carregar · 5 músicas · efeito de TV de tubo (CRT) · tela 16:9.

## 🌐 Publicar no GitHub Pages

1. Envie todos os arquivos desta pasta para a raiz do repositório.
2. Vá em **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, depois a branch **main** e a pasta **/ (root)**, e clique em **Save**.
4. Em 1 ou 2 minutos o jogo estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Para atualizar, basta substituir o `index.html` e fazer um novo commit.

## 📁 Arquivos

- `index.html`: o jogo completo, com imagens e música embutidas
- `favicon.ico`: ícone da aba
- `robots.txt`: pede aos buscadores que não indexem o site
- `.nojekyll`: faz o GitHub Pages servir os arquivos como estão
